Architecture · Four Orthogonal Dimensions & Four Anti-Hacking Locks

🛡️ 四维正交探针 × 四道物理防刷锁（为什么刷不烂？）

传统单向指标（如「多用语气词」「提高句长方差」）极易被模型钻空子。C-LongSlopBench 将所有连续特征锚定在多博主真实人类分布的双边区间 [P10, P90] 内，并绑定成对张力锁。

🔬 D1 微观气口与标点拐杖

联合监控中文口语缓冲词率（其实/说白了/吧/呢）与解释性标点拐杖总密度（破折号 —— + 括号注释 （E） + 冒号枚举 ：）。

M1_speech_buffer_rate M1_punct_crutch_total M3_MATTR_band

🔗 D2 跨句推进与信息流

基于 OSU Old-to-New 连贯链与 206 万字参考 LM 的逐词 Surprisal，检测相邻句实词/代词搭扣断裂率与句首生硬信息冲击。

M2_cohesion_break_rate UID_onset_minus_end_surp M2_new_topic_abrupt

🦴 D3 句式骨架与起手式克隆

抽离具体实词只保留词性序列（POS 4-gram）与各自然段首句词性模式，专抓「换词不换骨」的隐蔽排比与提纲填空同质化。

M3_opener_homogeneity M2_pos_template_rep

🏔️ D4 宏观回环与中段塌陷

基于 SciSlop 远距句子回环重合度与 ConStory 全文 30%–70% 中段具象锚点（数字/专名/引语）衰减率，捕捉长文中段空洞化。
