📋 方法出处（Provenance）
  1. ① Pre-AI 真人锚（24 篇）：本基准自建语料，陈皓 CoolShell / 阮一峰科技爱好者周刊等 2011–2022 Pre-AI 归档。
  2. ② 当代真人锚（31 篇）：本基准自建语料，云风 CodingNow / piglei / laixintao「卡瓦邦噶！」等当代独立技术博客。
  3. ③ Ours + Gate：本工作提出的「句段级处方单引导微修 + ParagraphQualityGate 段落门禁」（1-Pass）。处方协议参照 DeepMind DetectorScope (arXiv 2610.30006) 的 evidence-block 定向改写设计；门禁消融见下方 Table 3。
  4. ④ Few-Shot 模仿（5-Shot）：公共基线，复现 Catch Me If You Can? (EMNLP 2025 Findings) 的范文风格模仿改写协议。
  5. ⑤ Ours w/o Gate：本工作消融组——移除段落门禁、对所有处方段落一刀切微修，用于证明门禁必要性。
  6. ⑥ 原生 AI 基线（Paired-10）：本基准自建配对语料，与 10 篇真人长文同题的前沿 LLM 原生长文（未编辑；配对协议同 Catch Me If You Can）。
  7. ⑦ Zero-Shot 盲改：公共基线，复现 DeepMind DetectorScope Fig.5 的 Generic 泛化改写提示（仅给目标不给定位）。
  8. ⑧ TTM 两阶段：公共基线，Test-Time-Matching (arXiv 2507.16799) 的「先内容中性化 → 再逐句风格注入」解耦改写，3 轮迭代。
  9. ⑨ PA 人设对抗：本基准自建基线——Persona 人设注入 + 裁判反馈多轮对抗改写，设计参照角色扮演范式 IMPersona (COLM 2025) 与 TTM。
  10. ⑩ Checklist 规则：公共基线，单向禁用词表规则提示（复现 Catch Me If You Can 的显式约束改写：「禁用首先/此外，长短句交替」，无防代偿锁）。
📐 指标定义与计算方式
  • 总分（官方排名指标） = 0.7 × HumanPass(四维防刷) + 0.3 × (1 − 稀疏 AI 率)，其中 HumanPass = 100·exp(−0.35·防刷Z)。排行榜按总分排序。
  • 防刷 Z：四维正交探针（D1–D4）对多博主真人长文分布的双边偏离 Z-Score（锚定 [P10, P90] 区间，越界按超标距离重罚；含成对张力锁与事实红线）。越低越好，真人博客均值约 0.28–0.32。
  • 稀疏 AI 率：DetectorScope 式双极稀疏探针（中文 TF-IDF 字符 n-gram + ElasticNet，专名/数字掩码后训练）输出的 AI 概率。0.50 为决策边界。
  • 事实保真率：原子事实锚点（数字、专名、因果链）在改写后的保留比例；由确定性脚本抽验。
  • 改动%：改写产物的字符级 diff 比例（相对原文）。
  • D1 微观拐杖：解释性标点密度（破折号 —— + 括号注释 + 冒号枚举）与口语缓冲词赤字的合成 Z 值，抓「破折号/括号代偿」。
  • D2 跨句衔接：相邻句实词/代词搭扣断裂率 + 句首信息冲击（Surprisal 差），抓「剁短句导致断链」。
  • D3 骨架克隆：段首起手式同质化 + 词性 4-gram 骨架复读率，抓「换词不换骨」。
  • D4 宏观回环：跨段远距复述率 + 中段具象枯竭度，抓「提纲填空与车轱辘话」。
📎 参照指标（不参与排名）
  • LLM 盲判通过率：单分数 LLM-as-a-Judge（hy4）对每篇文本独立盲判 HUMAN/AI，通过率 = 判 HUMAN 篇数 / 总篇数。①② 真人锚与 ⑥ AI 基线各 24/32/10 篇，改写基线为 10 篇配对产物。该裁判单独检测 AUROC 仅 0.6000（见下表 Table 1），且可被毁灭式洗稿欺骗，因此仅作参照，不参与排名。
  • * 关于 Ours 两个方法（+Gate / w/o Gate）的 0% 盲判通过率：补跑实测（裁判 hy4，与全部基线同一协议；逐篇记录见仓库 results/llm_judge_ours_backfill.jsonl 与 results/llm_judge_ours_nogate.jsonl，两组均为 10/10 全判 AI）。这一「反直觉」结果恰恰是本基准核心论点的双面铁证：① 处方微修仅改 7.5%–13.7% 字符、宏观段落骨架与原文一致，而单分数裁判在评语中明确指出其因「按论文各节面面俱到铺陈、未捏造个人跑卡经历」而判 AI——它连保真 100% 的自然微修都判 AI，说明其判断层系统性失灵（对 TTM/PA 这类「捏造虚假人设经历、丢 15%–18% 事实」的毁灭式洗稿反而放行 90%）；② 反过来，它能被 48%–59% 的大改写骗过、却给不出任何可归因证据。这正是为什么本基准的官方排名指标是防刷 Z + 稀疏探针 + 事实保真，而非 LLM 裁判意见（裁判意见仅作参照列展示）。

📐 指标定义 · 传统 LLM 裁判是怎么打分的？
  • Heldout AUROC：在 212 篇零泄漏 Heldout 盲测集（6 位真人博主 + 多领域 AI 长文）上，以「AI/人类二分类」计算 ROC 曲线下面积及 1,000 次 Bootstrap 95% 置信区间；0.5 = 瞎猜，越高越好。
  • 真人误杀率 (FPR)：在 Heldout 真人博客长文 P88 标准阈值下，把 Pre-AI 真人长文（陈皓/阮一峰等）误判为 AI 的比例。
  • 原生 AI 检出 / 对抗改写检出：在同题配对集上，正确判出「10 篇未编辑 AI 长文」与「20 篇 TTM/PA 多轮人味洗稿长文」的比例。
  • LLM 裁判打分方式：单分数盲判协议——裁判模型（hy4，判据经 87 篇校准集校准，F1≈0.895）只见文本本身，不署名不比对，输出 {verdict: HUMAN/AI, confidence: 0-100, ai_tells: [...], human_tells: [...]} 单一 JSON；考察点为口语化程度、个人色彩、情绪波动、模板化结构、均匀节奏、升华式金句收尾等。它不做逐段归因、不输出可解释特征，因此对结构性 AI 味天然失明——这正是上表第 7 行 0.6000 与第 8–10 行的差距来源，也是本基准存在的理由。
Architecture · Four Orthogonal Dimensions & Four Anti-Hacking Locks

🛡️ 四维正交探针 × 四道物理防刷锁（为什么刷不烂？）

传统单向指标（如「多用语气词」「提高句长方差」）极易被模型钻空子。C-LongSlopBench 将所有连续特征锚定在多博主真实人类分布的双边区间 [P10, P90] 内，并绑定成对张力锁。

🕵️ 真实长文深度案例：当模型被禁止用破折号与句首英文时，如何发生「一逗到底」代偿逃逸？

在真实技术长文生成场景中（以最新论文 Accelerate Bench, arXiv:2611.20882 的 5,600 字中文深度解读为例），我们观察到了继「剁碎短句刷 Burstiness」「口水词轰炸」之后的第三种 Goodhart 代偿逃逸（The Comma-Splice Compensatory Escape）：当提示词明确要求大模型「禁用破折号/括号/冒号提示体、禁止句号后直接硬顶英文缩写（。E）」时，模型为了不触发句号后的句首惩罚，干脆消灭句号、把全篇本该打句号或冒号的地方全部偷换成逗号 ，，在 48 个正文段中造出 33 个含 90–182 字巨型流水句的粘连段落，并退化为冷冰冰的「作者/论文」第三人称审稿汇报腔。

🐍 逃逸机制 ①：一逗到底粘连长句

为了规避句号后的 。E 句首英文硬顶与冒号枚举惩罚，模型将并列分句全部用逗号粘连：全文平均句长飙升至 58.8 字（真人长文均值 38.4 字，P90 = 48.5 字），≥90 字超长粘连句占比达 31.9%（真人 P90 = 18.0%）。
