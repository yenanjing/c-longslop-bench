一句话讲清楚👉🏻 南京大学和腾讯优图最新研究Omni-Diffusion 是首个完全基于掩码离散扩散的任意到任意多模态模型，通过统一建模文本、语音、图像的联合分布，在无需额外输出模型的情况下实现了跨模态的理解与生成。

多模态模型的架构困境

GPT-4V、Gemini 这些多模态大模型已经很擅长处理文本、图像、语音了。但它们都有一个共同的架构基因：自回归生成。

自回归的本质是串行的——给定前 N 个 token 预测第 N+1 个，不断重复。这种方式虽然有效，但存在固有瓶颈：

串行生成限制了并行计算效率

难以建模不遵循从左到右顺序的跨模态依赖

生成轨迹难以被精确控制

与此同时，扩散模型在图像生成领域已经证明了自己。那么问题来了：能不能完全抛弃自回归，用扩散模型从头构建一个多模态系统？

南京大学和腾讯优图实验室的研究团队用 Omni-Diffusion 给出了答案。

模型概述

Omni-Diffusion 将文本、语音、图像统一编码为离散 token，通过掩码扩散过程建模联合分布

Omni-Diffusion 是首个基于掩码离散扩散（Mask-based Discrete Diffusion）的任意到任意多模态语言模型。它不依赖额外的输出模型来转换 LLM 的隐藏状态，而是直接在一个统一的离散表示空间中建模多模态分布。

这意味着模型能够在共享的语义空间中实现不同模态的对齐，从而获得统一的理解和生成能力。

模型架构

Omni-Diffusion 架构：通过统一的掩码 token 预测实现多模态理解和生成

图像 Tokenization

采用预训练的 MAGVIT-v2 作为图像 tokenizer。它通过视觉编码器将图像压缩为紧凑表示（下采样因子 f=16），然后用量化器（codebook 大小 8192）将紧凑表示转换为离散 token。这些 token 被用于视觉理解和生成任务。

语音编码器和解码器

语音编码使用 SenseVoiceSmall，它利用带记忆的自注意力网络从输入语音中提取语义丰富的表示，再通过轻量级 MLP adapter 投影到扩散模型骨干的隐藏维度。

语音生成采用 GLM-4-Voice 解码器。其语音 tokenizer 通过有限标量量化层（codebook 大小 16384）将语音转换为离散 token，token 速率为 12.5 Hz。模型预测的语音 token 最终由 GLM-4-Voice 解码器重建为波形。

LLM 骨干

以 Dream-7B（一个预训练的离散扩散语言模型）为基础模型。为支持多模态处理，词表扩展了 16384 个语音 token 和 8192 个图像 token。除了扩展词表及对应的嵌入层和输出层，扩散模型的架构保持不变。

三阶段渐进式训练流程

三阶段训练流程：从视觉-语言对齐开始，逐步扩展到语音模态，最后优化语音驱动的视觉交互能力

阶段一：视觉-语言预对齐

在文生图和图像描述任务上优化预训练的扩散语言模型，使视觉模态与预训练语言模型的语义空间对齐。

阶段二：语音-视觉-语言联合对齐

保留阶段一的视觉-文本数据集，引入自动语音识别（ASR）和文本转语音（TTS）数据来促进语音-文本对齐。

阶段三：语音驱动视觉交互能力提升

在构建的 SDVI（Speech-Driven Visual Interaction）数据集上微调模型，该数据集包含需要同时处理语音和视觉数据的样本。同时引入语音问答（SQA）和视觉问答（VQA）数据。

SDVI 数据集构建

为提升模型通过语音指令进行视觉交互的能力，研究团队构建了 Speech-Driven Visual Interaction 数据集，包含语音视觉问答和语音生成图像两类数据。

语音视觉问答

以 LLaVA-OneVision 为数据源，使用 Cosyvoice2 将文本问答对转换为语音。处理流程包括：

过滤掉包含数学计算或编程的样本（口语对话中不常见）

将所有选择题改写为开放式问答

移除答案长度超过 100 词的样本（口语对话倾向简洁）

为防止模型过拟合于特定声音，问题部分使用 GigaSpeech 数据集随机采样的 1000 个语音样本进行声音克隆转换，答案部分使用固定声音转换。最终数据集包含超过 30,000 个样本。

语音生成图像

选择 Blip3o-Pretrain-JourneyDB 作为数据源（文字流畅、图像质量高），同样使用 Cosyvoice2 进行声音克隆转换，得到 30,000 个语音-图像对。

衰减尾填充掩码策略

为支持变长生成，采用尾填充增强策略：在每个数据样本末尾添加随机数量的填充 token。训练时，原始 token 和填充 token 都被随机掩码并作为预测目标。

ASR 任务：初始 token 长度设为语音 token 长度的 0.2 倍

局限性与未来方向

尽管 Omni-Diffusion 展示了扩散模型在多模态领域的潜力，但仍有一些挑战：

计算开销

：扩散过程的多次迭代增加了推理时间，相比单次生成的自回归模型效率较低。

生成精度

：在需要精确控制的生成任务上（如精确的文字渲染），扩散模型仍有改进空间。

模态扩展

：当前模型主要支持文本、语音、图像三种模态，视频、3D 等更多模态的整合有待探索。

未来，随着一致性模型、渐进蒸馏等扩散模型优化技术的发展，这些限制有望被逐步克服。
